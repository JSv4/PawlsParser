## Requirements

### Poppler
- **Windows**: Poppler will be automatically downloaded and set up when needed
- **Linux**: Install via package manager (e.g., `apt-get install poppler-utils`)
- **macOS**: Install via Homebrew (`brew install poppler`)

### Tesseract
Tesseract OCR is required for OCR functionality. Install it for your platform:
- Windows: Download installer from [UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki)
- Linux: `apt-get install tesseract-ocr`
- macOS: `brew install tesseract`
